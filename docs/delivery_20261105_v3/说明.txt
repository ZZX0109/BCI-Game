如何体验
--------
Mac 本机：双击“启动本机预览.command”。需 Python 3.10 或以上；首次启动会将官方
Qt 依赖安装到本文件夹的 .preview-venv，后续不再下载。也可在已有 PySide6 环境运行
python preview.py。顶部可切换七款、暂停、重新开始。此入口是键鼠预览，不采集脑电。

Windows Neuralife：设置 NEURALIFE_EXE 为你的 Neuralife.exe 路径，运行 play.bat 游戏ID。
例如 play.bat hanoi；不填ID默认抓娃娃。仍保留原 D:\program\AIT\Neuralife\bin\Neuralife.exe
作为未设置变量时的默认路径。鲁班锁会启用 RHI 三维后端。
不要只复制 Main.qml：新增的 QML 组件和所有 assets、shared-ui 都是运行依赖。

实际操作
--------
抓娃娃：正视大画面看左右，左上侧视图看前后。按住四个方向按钮或方向键调整，
确认两个视图均对准黄色玩具后点击抓取。下降后自动完成本次动作。

汉诺塔：直接按住顶盘拖到目标柱松手；也可点源柱再点目标柱，全程不需要键鼠混用。
大盘不能压小盘，非法或场外释放会回到原柱。仍可独立使用宿主方向＋确认。

鲁班锁：选带编号的木件，观察贴着木件的 A/B 端箭头，然后点击对应箭头或沿长轴拖动。
绿色表示能完整抽出，黄色表示只能滑动一段，受阻会提示挡住它的木件。
空白拖动/右键转视角，滚轮缩放；可随时换件、撤销、复位视角或整个机关。
键盘/脑控：左右换件，上下选择下方操作，确认执行；观察模式确认返回操作。

追光球：鼠标带着浅灰绿球追踪暖金色目标，鼠标不会故意拖后；最后一轮目标会短暂隐藏。
共五轮自动推进。脑控仍由宿主指针输入，原始和显示轨迹分开记录。

推箱子：点击人物相邻的亮格移动或推动箱子，也可点击下方方向按钮。
全部箱子推到绿色圈即可过关；推死后可稳定地撤销或重开，不会三秒后夺走恢复机会。

精准打靶：移动鼠标瞄准，左键射击。射后0.5秒显示反馈，再进入下一靶。
定点移靶模式先点蓝色起点，再射击目标，用于保证距离条件真实。

过马路：观察行人灯和车流，在安全区等绿灯，按住前进、松开停止，也可后退。
车辆灯、停止线和排队遵循同一套状态。路中仍有人时车辆不会因绿灯倒计时结束直接启动。
“前进一步”是较小的单次移动；不会代替玩家自动走完整段路。

--------
所有七款在 Mac 的真实 Qt/Metal 预览窗口加载、暂停、继续、切换通过，无 QML 错误。
汉诺塔三种尺寸真实鼠标拖放，五局全拖通关；打靶四种尺寸各8枪实际鼠标命中；
追光球四种尺寸即时跟手并推进五轮；推箱子五关36步/18推动及点击、暂停回归；
抓娃娃双视图、按住松开、阶段/暂停保护；鲁班锁真实3D拾取/拖动及三关输入通关；
过马路五关和local/BCI模拟输入各610秒车流与行人绿灯安全检查。
验收摘要在“验证结果.json”。详细测试脚本和原始证据保留在本次Codex工作区。

尚未验证
--------
没有 Neuralife.exe 的实际部署环境或 EEG 硬件，因此不声称真实脑控设备已验收。
宿主指针约定：x/y 的全画布范围由 game.width/height 声明；游戏自行映射到实际场景。
若宿主发送场景局部坐标而仍声明全画布尺寸，需要在宿主适配层修正。
鲁班锁需要可用的 QtQuick3D 和 RHI 图形后端。软件离屏后端不能代替三维验收。
本机预览已在真实 Cocoa/Metal 后端测试；不同 Windows GPU/宿主Qt版本仍需集成检查。

字体与屏幕适配
--------------
所有游戏的界面文字和道路 Canvas 文字共用字体设置。本机已验证为苹方 PingFang SC；
Windows 优先使用 Microsoft YaHei UI / Microsoft YaHei，其他平台优先选用可用的
Noto Sans CJK SC。没有上述字体时使用系统字体。未打包或安装额外字体。
鲁班锁关键状态文字、交通信号文字及部分提示已放大；品牌名、字母端点、按键名保留。

七款场景根据实际窗口可用空间布局，背景统一为#050505。道路按宽屏延展，打靶/追光球
互动范围填实际场景，抓娃娃双视图、汉诺塔柱间距、推箱子格子、鲁班锁视口与工具栏
均响应窗口变化；全屏按钮或F11进入全屏，Esc退出。汉诺塔底座与推箱子外墙为游戏物体。

脑控输入保护
------------
抓娃娃在bci/brain来源下默认离散脉冲；追光球和打靶等待首个有效二维指针后再开始计时。
停止后的旧会话不会被继续信号复活，只有新的开始信号可重置。详见交付验收说明.txt。

本轮整体窗口适配
----------------
新增LegacyWindowFill，七款均接入。对严格匹配的全窗口1000:700居中缩放外层，
将外层width/height绑定到真实窗口父容器、scale设为1，持续跟随窗口尺寸变化。
卸载时恢复宿主原绑定/值；未知嵌入布局不强改。设计尺寸声明1000/700保持兼容。
此修复已实现，不再只是诊断。鲁班锁本轮仅接入共享画布适配，玩法优化暂缓。

模拟宿主28案例通过。打靶/追光球在固定1000x700与动态宿主坐标范围下，离屏及
原生Cocoa的中心/角点、鼠标/脑控映射及resize检查通过。原生实际尺寸以证据记录为准。
Windows真实Neuralife仍为NOT TESTED；七模块外部加载桥内部实现仍未知。
F12是可选fallback，显示适配状态；不要求先提供截图才能应用修复。
