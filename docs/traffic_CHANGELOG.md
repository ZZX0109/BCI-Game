# traffic CHANGELOG

## 0.4.0（V4 重做，2026-11-03）

### 用户可见行为

- **玩法彻底替换**：删除「看红绿灯按确认 → 播放 1.1 s 固定过街动画」的 Go/No-Go 主循环，
  改为斜侧视街道躲车——按住 → 前进、按住 ← 后退，松开立即停下，随时可以退回。
- 新增五关 `C01–C05`：车道数 2 → 5，车速与出车密度递增，C04 大车（truck）占比高形成遮挡。
- 撞车 → 红色闪屏 + 「被撞到了」横幅，1.5 s 后**同关重试**（同种子，车流一致，可复盘）。
- 通关 → 「安全到达对岸」横幅 + 用时/碰撞次数，1.4 s 后自动进入下一关；第五关结束才 `game.finish()`。
- 场景重画：楼群窗光、绿化带与行道树、对岸人行道与路灯、逐车道交替明暗、分道虚线、
  斑马线、路缘石、双向车辆（车头灯指示方向）、带步行摆腿动作的行人。

### 关键实现决策

1. **碰撞只认世界坐标**：屏幕像素完全不参与判定，避免 V3「准星与命中点两套坐标系」类问题。
2. **固定子步**：宿主本身按 8 ms 步进，游戏再以 8 ms 为上限二次切分，高速车不会穿越玩家。
3. **公平性前置校验**：车道事件生成后，若前车车尾到后车车头净空 < 1.05 s 就顺延后车，
   从源头排除「必死车流」，并把 `minClearSec` / `fairnessFix` 写进日志。
4. **对象池渲染**：车辆 delegate 固定 24 个，只更新属性，不逐帧重建，避免 60 fps 下的对象抖动。
