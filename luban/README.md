## 三关

1. 两件穿榫：2号纵梁穿过1号横梁的贯通卯眼；先退出纵梁，横梁才能沿长轴移动。
2. 三件交叉锁定：3号中心锁销穿过2号纵梁的销孔；退出锁销后，纵梁解除阻挡，再拆横梁。
3. 四件止退锁定：4号细销穿过3号中心锁销外端的横孔；逐层解锁 4→3→2→1。

以上顺序是几何验证的结果，并非游戏内放行表。每件可从 A/B 两端退出；两端路径均校验。观察、试错、撤销不会跳过碰撞。此为原创简化榫销教学结构，并非传统六件鲁班锁的复刻。训练规则为只沿构件长轴平移；未验证允许任意旋转的全自由度锁止，也未验证摩擦、木材强度或加工公差。

## 操作

- 左右换件，上下选操作，确认执行。鼠标可点选木件或左侧编号，拖动木件沿其长轴移动。
- A/B端按钮提供与拖动等价的操作；红色受阻说明指出真实挡路件。
- “查看榫槽”：隔离显示选中件的真实孔槽，可左右换件或转动视角；此时禁止抽取。点“返回装配”继续。
- “几何提示”：读取当前碰撞状态，说明 A/B 两端及挡路编号。
- “撤销一步”按实际操作记录复原上一件；“复位机关”恢复本关。完成后确认进入下一关，最后确认结束。
- 拖空白或右键旋转，滚轮缩放；“转动视角”也支持宿主方向输入。
