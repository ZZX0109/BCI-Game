# VR 平面提示与菜单输入调整（2026-11-19）

用户反馈移动时平面提示持续跟随导致不适，随后要求取消所有射线菜单选择。实现与已安装交付如下。

## 行为

- 三款游戏的 VR UI 均取消射线命中、点击、拖拽及光线显示；保留兼容组件接口，不再创建射线。左摇杆上下选择，右手柄 A 确认，滑块左右调整；X 暂停。游戏动作仍用各自手柄按键。
- 抓娃娃接入共享菜单导航，开始/继续/结果页默认选中主要操作，重开确认默认选保留进度。菜单 Canvas 激活后再设置选择，避免首次 A 无目标。
- 推箱子和过马路：每次应用启动首次进入游戏时显示操作说明，最多 6 秒；移动、分段转向或明显头部位移/转头立即撤下，暂停或重试不会重播。
- 这两款的游戏过程取消常驻二维状态板、计时板、方向浮标等。情境提示按文字在本次 UI 会话去重，停下时最多显示 3 秒；移动后不会重新补播同一提示。
- 游戏中的 Canvas 不再因移动 0.75 米或转头 55 度自动追到眼前。菜单/暂停/结算仍可居中；操作说明在暂停菜单可重新查看，过马路目的地也可在暂停中查看。
- 普通桌面 UI 的上述显示逻辑不变。没有声称能够消除所有 VR 不适；人工移动本身仍可能造成不适。

参考：[Meta 头部交互说明](https://developers.meta.com/vr/design/head/)、[Meta 移动舒适性指南](https://developers.meta.com/vr/design/locomotion-comfort-usability/)。指南只作为设计依据，不代替本项目佩戴实测。
